# Data Requirements
To run the analysis script, you must download the following supplementary files from the **Gonçalves et al. (2022)** study:

* [cite_start]**Source Study:** [Pan-cancer proteomic map of 949 human cell lines](https://doi.org/10.1016/j.ccell.2022.06.010) [cite: 222]
* [cite_start]**File 1:** `mmc2.xlsx` (Cell line level sample info) [cite: 261-263]
* [cite_start]**File 2:** `mmc3.xlsx` (Full protein matrix) [cite: 267-270]

### Instructions
1. [cite_start]Visit the [Cancer Cell link](https://doi.org/10.1016/j.ccell.2022.06.010)[cite: 223].
2. Download the Supplemental Information files.
3. Place `mmc2.xlsx` and `mmc3.xlsx` directly into this `/data` folder.
